# Sales Analytics Project (SQL + Python)

## Project Overview
This project analyzes transactional sales data to extract business insights using SQL and Python. The workflow covers data extraction from a MySQL database, data cleaning in Python, exploratory data analysis (EDA), and business-focused analysis.


## Tools & Technologies
- MySQL (data storage and querying)
- Python (pandas, matplotlib)
- SQLAlchemy (database connectivity)
- VS Code
- Jupyter Notebook


## Data Cleaning
- Loaded transactional data from MySQL into Python
- Removed invalid quantity and unit price values
- Handled missing customer and invoice identifiers
- Converted date columns to proper datetime format
- Created a revenue column for analysis


## Key Analysis & Insights
- Calculated core business KPIs: total revenue, total orders, total customers, and average order value (AOV)
- Analyzed monthly revenue trends to identify seasonality
- Identified top customers contributing the highest revenue
- Evaluated country-wise revenue distribution
- Observed revenue concentration among a small subset of customers

  ## Business Recommendations
- Focus on retaining high-value customers to reduce dependency risk.
- Investigate seasonal peaks to optimize inventory and promotional strategies.
- Strengthen presence in top-performing geographic markets.
- Implement strategies (bundling, upselling) to increase Average Order Value.


## Key Learnings
- Practical SQL joins and aggregations for business analysis
- Data cleaning and validation using Python
- Time-based and customer-based analytical thinking
- Translating data outputs into business insights


## Conclusion
This project demonstrates an end-to-end data analytics workflow, combining SQL and Python to transform raw transactional data into meaningful business insights.
